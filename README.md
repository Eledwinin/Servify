# Servify - Aplicación Móvil

Servify es una plataforma móvil diseñada para conectar clientes que necesitan reparaciones y mantenimiento en el hogar con trabajadores y técnicos calificados. La app permite explorar servicios, visualizar perfiles de profesionales, solicitar contrataciones y dar seguimiento al estado de los trabajos.

---

## 🛠️ Tecnologías y Dependencias

* **Lenguaje:** Kotlin
* **Interfaz de usuario:** Jetpack Compose con Material 3
* **Arquitectura:** MVVM (Model-View-ViewModel)
* **Consumo de API:** Retrofit 2 + Gson Converter
* **Concurrencia:** Corrutinas de Kotlin + StateFlow
* **Servicio de Correos:** Brevo API (envío de correos y códigos de recuperación).
* **Navegación:** Jetpack Navigation Compose
* **Backend:** Node.js, Express y MySQL (Render)

---

## ⚙️ Requisitos Previos

* Android Studio Ladybug o superior.
* JDK 17 o superior.
* Dispositivo físico o emulador con Android 8.0 (API 26) o superior.
* Conexión a internet para comunicarse con la API.
